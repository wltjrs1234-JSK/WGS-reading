# YeastWGS Studio — *S. cerevisiae* (`sacCer3`) 로컬 WGS 비교 및 서열 추출기

사내 보안 환경에서도 안전하게 사용할 수 있도록 **100% 브라우저 클라이언트 사이드(Zero-Upload)** 방식으로 동작하며, IGV Web과 동일한 워크플로우를 제공하는 *S. cerevisiae* WGS 분석 웹 툴입니다.

## 주요 기능

1. **`sacCer3` (전체 17개 염색체 + 7,728개 유전자) 기본 탑재**
   - 별도의 Reference FASTA / GFF3를 구해 올리지 않아도 시작 즉시 **`all`, `chrI`~`chrXVI`, `chrM`** 전체 염색체와 S288C 유전자 트랙이 준비됩니다.
   - 필요 시 `Genome -> 변경`에서 사용자 로컬 `.fasta`/`.fai`/`.gff3` 파일로 교체할 수 있습니다.
2. **로컬 BAM + BAI 즉시 트랙 추가 (단일 균주 / 다중 균주 자동 전환)**
   - 브라우저 화면 어디에나 `.bam` + `.bai` 파일을 드래그 앤 드롭하거나 **[+ BAM/BAI 트랙 추가]** 버튼을 누르면 `File.slice()` 기반 바이트 단위 랜덤 액세스로 즉시 매핑됩니다.
   - 1개 BAM을 넣으면 **Reference vs 균주1(2-Way)**, 2개 이상을 넣으면 **Reference vs 균주1 vs 균주2(3-Way)** 모드로 자동 동작합니다.
   - *S. cerevisiae* 염색체 별칭(`chrI`↔`I`↔`NC_001133.9`↔`BK006935.2`, `chrM`↔`NC_001224.1`↔`MT`↔`chrmt`)을 자동 매칭합니다.
3. **IGV 스타일 고대비 뷰어 & 조작**
   - 상단 염색체 Ideogram(빨간 뷰포트 표시), `all` 전체 지놈 커버리지 뷰, 회색 커버리지 위 변이 비율 컬러 틱, 중성 회색 리드 위 불일치 염기·보라색 `I` 삽입 마커, 하단 `RefSeq / SGD` 유전자 트랙을 제공합니다.
   - **마우스 휠**: 현재 염색체 내 좌우 이동 / **`Ctrl + 휠`**: 확대·축소 / **`Crosshairs` · `Center Line`** 지원.
   - 상단 통합 검색창에 `chrV:115,600-117,600` 또는 유전자명(`URA3`, `ACT1`, `COX1`, `YER134C` 등)을 입력하면 자동완성 목록에서 즉시 이동 및 추출할 수 있습니다.
4. **특정 부위 드래그 선택 & 실제 균주 서열 추출**
   - **`Shift + 마우스 드래그`** 또는 **[드래그 서열 추출]** 모드(또는 유전자 클릭)로 원하는 부위를 선택하면 `Esc`·우클릭·버튼으로 언제든 선택 취소가 가능합니다.
   - CIGAR(`M/I/D`)를 반영한 **실제 DNA 서열(Ungapped)** 과 **다중정렬(Aligned)** 출력, 역상보 변환, Haploid/Diploid(IUPAC), 핵(Table 1)·미토콘드리아(Table 3) 번역 비교 및 FASTA/TSV/NCBI BLAST 연계를 지원합니다.

## 실행 방법

1. 폴더 내 **`start_viewer.vbs`** (권장, 검은 CMD 터미널 창 없이 백그라운드 무창 실행) 또는 `start_viewer.bat`를 더블 클릭하면 자동으로 **Google Chrome**으로 `http://127.0.0.1:4173`이 열립니다. (Chrome 미설치 시 시스템 기본 브라우저로 열립니다.)
2. 백그라운드 로컬 웹 서버를 종료할 때는 `stop_viewer.vbs`를 실행하세요.
3. `sacCer3`가 이미 로드된 상태에서 보유하신 로컬 **`.bam` + `.bai` 파일을 화면으로 드래그 앤 드롭**하세요.
